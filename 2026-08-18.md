### [A Preview of DuckDB v2.0](https://duckdb.org/2026/08/17/duckdb-20-highlights) · 619 points
DuckDB v2.0 выводит движок за пределы чисто embedded-режима: новый протокол Quack и `CONNECT` позволяют запускать DuckDB как сервер и направлять запросы в удалённые базы, при этом локальный режим остаётся. В релиз также входят async I/O, triggers, новый storage format и SQL parser, а remote pushdown умеет отправлять работу в PostgreSQL и MySQL вместо вытягивания таблиц локально. Команда показывает recursive CTE, ускорившийся с **4,90 до 0,12 с — примерно в 40×**. v2.0 ожидается осенью; часть новых интерфейсов пока preview.
> **[Комментарии](https://news.ycombinator.com/item?id=49330781)**
> Пользователи ценят DuckDB как один движок поверх Parquet, S3, PostgreSQL и других источников; Quack особенно полезен там, где embedded-модель упиралась в concurrency. При этом server mode воспринимают скорее как дополнительный режим, а не замену простому in-process использованию.
### [Wiz Red Agent нашёл путь во внутренний Jira Snowflake через GitHub Actions](https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug) · 365 points
Wiz Red Agent нашёл command injection в GitHub Actions репозитория `snowflakedb/snowflake-connector-net`: заголовок GitHub issue напрямую попадал в `run:`, поэтому специально созданный issue позволял выполнить команды в runner. Агент извлёк Jira-token и подтвердил read-доступ к внутренним engineering и security-проектам Snowflake. Уязвимость была активна пять дней, а GitHub Advanced Security просканировал merged PR, но не заметил её. Wiz отдельно уточнил раннюю формулировку: Copilot был co-author/reviewer PR и пометил его all-clear, но неизвестно, был ли сам уязвимый код создан AI. Snowflake исправила workflow в день disclosure и заявила, что другого несанкционированного доступа по логам не было.
> **[Комментарии](https://news.ycombinator.com/item?id=49331423)**
> Главный технический спор — это давно известный класс GitHub Actions injection, а не новая «AI-уязвимость»: attacker-controlled event data нельзя напрямую интерполировать в shell. Новое здесь — автономный offensive agent быстро нашёл баг, эксплуатировал его и проверил blast radius.
